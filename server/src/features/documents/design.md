# Create Document

## Requirement

An authenticated user should be able to create a new document.

---

## Business Rules

- User must be authenticated.
- Every document has one owner.
- Default title is "Untitled Document".
- Content is initially empty.
- UUID is generated by the backend.
- createdAt and updatedAt are generated by the backend.

---

## API

POST /documents
